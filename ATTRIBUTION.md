# Asset attribution

## `assets/character.glb`

This file is a verbatim copy of `Fox.glb` from the Khronos glTF Sample Assets
repository, renamed for use as the companion character.

- **Source file:** <https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Fox/glTF-Binary/Fox.glb>
- **Model directory / metadata:** <https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox>

Credits and licenses (as stated by the upstream model metadata):

- **Model:** PixelMannen — [Creative Commons Zero v1.0 Universal (CC0)](https://creativecommons.org/publicdomain/zero/1.0/legalcode)
- **Rigging & animation:** tomkranis — [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/legalcode)
- **Conversion to glTF:** @AsoboStudio and @scurest — [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/legalcode)

The glTF contains three named clips: `Survey` (mapped to idle/breathing),
`Walk`, and `Run` (mapped to the happy reaction). The original glTF conversion
discussion is linked here: <https://github.com/KhronosGroup/glTF-Sample-Models/pull/150#issuecomment-406300118>.

The asset was downloaded during development and is committed with the project;
the application never downloads it at runtime.
