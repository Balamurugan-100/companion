# 07: Tasks and notes

**What to build:** The panel supports quick task capture, completion and removal, plus short plaintext notes. All content is stored locally and survives restart. Completing a task produces a small character reaction, keeping the companion present without turning into a chatbot.

**Blocked by:** 03: Local store and settings; 04: Reactive personality and mood check-in.

**Status:** done

- [ ] Tasks can be added, completed and deleted.
- [ ] Notes can be created, edited and deleted.
- [ ] Task and note content persists across restart.
- [ ] Task completion triggers a character reaction and bubble.
- [ ] Store CRUD is covered by tests.
