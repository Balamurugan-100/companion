# 08: Daily summary and calm mode

**What to build:** A summary view aggregates today's focus minutes and completed tasks from local data. Calm mode is a single toggle that dims the UI, slows character animation and suppresses non-essential bubbles, giving the user a quieter companion on demand.

**Blocked by:** 05: Focus timer and session history; 06: Breathing and grounding tools; 07: Tasks and notes.

**Status:** done

- [ ] Summary shows today's focus minutes and completed tasks from persisted data.
- [ ] Calm mode toggle visibly changes the UI and animation speed.
- [ ] Non-essential bubbles are suppressed while calm mode is on.
- [ ] Calm mode preference persists across restart.
- [ ] Aggregation logic is unit-tested.
